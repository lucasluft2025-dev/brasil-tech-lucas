# Brasil Tech Marketplace — protótipo

## O que já funciona no navegador
- Página inicial estilo marketplace com navegação, categorias, banners e benefícios.
- Catálogo de produtos com busca, filtros por categoria e faixa de preço, ordenação.
- Cards com imagens ilustrativas, avaliações e preço demonstrativo.
- Favoritos e sacola com quantidade, remoção e cálculo de subtotal.
- Modal de entrada/cadastro demonstrativo e formulário de newsletter demonstrativo.
- Layout responsivo para celular e desktop.

## Importante antes de vender
Este é um protótipo front-end. Não existe ainda:
- Banco de dados, login real ou painel de administração.
- Estoque sincronizado, gestão de pedidos ou área de vendedor.
- Checkout, PIX, Mercado Pago ou processamento de pagamento.
- Cálculo real de frete, rastreamento, emissão fiscal ou políticas publicadas.

Os preços, avaliações, imagens e produtos são dados ilustrativos. Revise e substitua tudo pelos dados reais da loja antes de publicar. Não anuncie avaliação, estoque, prazo ou garantia sem confirmação.

## Como abrir
Extraia o ZIP e abra `index.html` no navegador. Para publicar a demonstração, envie a pasta para uma hospedagem estática como Netlify ou Vercel.

## Próxima etapa de produção
Para virar marketplace operacional, conectar backend + banco de dados + autenticação + painel admin + gateway de pagamento + frete e gestão de pedidos. Recomenda-se implementar e testar cada integração antes de aceitar pagamentos.
